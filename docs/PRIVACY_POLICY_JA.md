# MemoBrain プライバシーポリシー

最終更新日: 2026-08-17

## 1. アプリについて

MemoBrain（以下「本アプリ」）は、Androidの共有機能を利用して、テキスト、URL、画像、動画、PDF、文書等を、利用者が設定した Dify 環境へ送信するクライアントアプリです。また、開発者管理の広告・案内ページと、利用者が設定したDify公開Web Appを、それぞれ分離したアプリ内WebViewで表示するAIチャット画面を提供します。

**本アプリの利用には Dify 環境が必須です。本アプリ単体では保存機能を利用できません。**

## 2. 本アプリが取り扱うデータ

利用者が明示的に共有・設定した場合に限り、次のデータを取り扱います。

- 共有テキスト、URL、補足メモ
- 利用者が共有した画像、動画、PDF、文書等
- 利用者が設定した Dify API Base
- 利用者が設定した Dify App API Key
- 利用者が設定した Dify Web App URL

本アプリは、連絡先、通話履歴、SMS、位置情報等へのアクセス権限を要求しません。DifyのWeb画面でファイル選択等を行う場合は、利用者の操作によりAndroidのシステムファイル選択画面が開くことがあります。

## 3. Difyへの送信

共有されたデータは、利用者が本アプリに設定した Dify API Base へ HTTPS で送信されます。

本アプリには、開発者が管理する Dify API URL や Dify API Key はあらかじめ組み込まれていません。利用者自身が Dify 接続先を設定します。

Dify側に送信されたデータの保存期間、Knowledgeへの保存、ログ、バックアップ、利用するLLMプロバイダーやプラグインへの送信については、利用者が構築・設定した Dify 環境および関連サービスの設定・プライバシーポリシーに従います。Dify DSL v0.3.5のナレッジ補完機能を使用すると、Knowledgeに十分な情報がない場合は確認メッセージを表示します。利用者が `Web調査:` を付けて明示的に送信した場合に限り、検索語句、取得情報、生成対象が利用者の設定したGeminiサービスへ送信され、Google Search Groundingで処理されます。生成された記事と参照URLは利用者のKnowledgeへ登録されます。

## 4. 端末内の一時保存

バックグラウンド送信を実現するため、共有データを一時的に端末へ保存する場合があります。

本アプリでは次の保護を行います。

- アプリ専用領域に保存
- Android Keystore を利用した AES-GCM 暗号化
- 送信処理中のみ一時復号
- 送信成功後に削除。最終失敗時は手動再送のため、作成から最大24時間だけ暗号化したまま保持
- 未送信の場合も最大24時間で削除
- Androidバックアップおよび端末移行バックアップの対象外
- 平文HTTP通信を禁止

送信履歴には送信日時、データ種別、送信状態、重複判定用ハッシュを保存します。本文、URL、ファイル名、Difyレスポンスは履歴へ保存しません。履歴はAndroid Keystoreを利用して暗号化し、最大100件・30日間保持します。URLは正規化後、ファイルは内容からSHA-256ハッシュを生成して重複判定に使用します。

ただし、端末やOSの挙動、ストレージ媒体の特性等により、物理的な完全消去を保証するものではありません。

## 5. Dify接続情報

Dify API Base、Dify App API Key、Dify Web App URL は、Android Keystoreを利用して暗号化し端末内に保存します。

これらの値は本アプリの配布APK/AABには含まれません。利用者はアプリ内の接続設定から削除できます。

## 6. WebViewと広告について

本アプリはネイティブのAdMobバナー広告を表示しません。また、AdMob App IDやBanner Ad Unit IDをAPKへ組み込む構成ではありません。

AIチャット画面では、開発者管理の広告・案内用HTTPSページと、利用者が設定したDify公開Web Appを別々のAndroid WebViewで表示します。広告ページにはGoogle AdSense等のWeb広告が表示される場合があります。利用者のDify URLは広告ページへ送信されません。

本アプリはGoogleの WebView API for Ads を利用するため Google Mobile Ads SDK を含み、対象WebViewを `MobileAds.registerWebView()` で登録します。本アプリでは Android Advertising ID (`AD_ID`) 権限をマニフェストから削除しています。ただし、WebView内の広告配信や不正防止等に伴い、Googleや広告関連サービスがIPアドレス、デバイス関連情報、広告とのインタラクション等を処理する場合があります。

WebView API for Adsでは、Androidネイティブ側で取得した同意状態がWeb広告へ自動的に引き継がれるわけではありません。広告を表示するWebページでは、そのサイト/ページの管理者が適用される法令・Google要件に応じてWeb側の同意管理/CMPを設定する必要があります。

Googleによるデータ処理についてはGoogleのプライバシーポリシーおよび広告関連ポリシーをご確認ください。

## 7. ログ・通知

本アプリは独自のアクセス解析SDKやクラッシュ解析SDKを組み込んでいません。

保存完了通知にはメモ本文、URL、ファイル名、Difyレスポンス本文を表示しません。Dify APIのエラーレスポンス本文も通知やアプリ独自ログへ保存しない設計です。

## 8. スクリーンショット等

本アプリは共有内容、API設定、チャット画面がOSのタスクスナップショット等へ残るリスクを低減するため、Androidのセキュアウィンドウ設定を利用します。

## 9. データの削除

端末内のDify接続情報はアプリ内の「Dify接続設定」から削除できます。

アプリをアンインストールすると、通常は本アプリのアプリ専用領域に保存されたデータも削除されます。

Difyへすでに送信済みのデータは、本アプリのアンインストールでは削除されません。Dify側で削除してください。

WebView内で表示されるWebページ、Dify、広告サービス等に保存されたCookie・サーバー側データについては、それぞれのサービスの設定・ポリシーに従います。
