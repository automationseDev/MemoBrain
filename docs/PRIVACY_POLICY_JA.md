## 1. アプリについて

MemoBrain（以下「本アプリ」）は、Androidの共有機能を利用して、テキスト、URL、画像、動画、PDF、文書等を、利用者が設定した Dify 環境へ送信するクライアントアプリです。

**本アプリの利用には Dify 環境が必須です。本アプリ単体では保存機能を利用できません。**

## 2. 本アプリが取り扱うデータ

利用者が明示的に共有した場合に限り、次のデータを取り扱います。

- 共有テキスト、URL、補足メモ
- 利用者が共有した画像、動画、PDF、文書等
- 利用者が設定した Dify API Base
- 利用者が設定した Dify App API Key

本アプリは、連絡先、通話履歴、SMS、位置情報、カメラ、マイク等へのアクセス権限を要求しません。

## 3. Difyへの送信

共有されたデータは、利用者が本アプリに設定した Dify API Base へ HTTPS で送信されます。

本アプリには、開発者が管理する Dify API URL や Dify API Key はあらかじめ組み込まれていません。利用者自身が Dify 接続先を設定します。

Dify側に送信されたデータの保存期間、Knowledgeへの保存、ログ、バックアップ、利用するLLMプロバイダーやプラグインへの送信については、利用者が構築・設定した Dify 環境および関連サービスの設定・プライバシーポリシーに従います。

## 4. 端末内の一時保存

バックグラウンド送信を実現するため、共有データを一時的に端末へ保存する場合があります。

本アプリでは次の保護を行います。

- アプリ専用領域に保存
- Android Keystore を利用した AES-GCM 暗号化
- 送信処理中のみ一時復号
- 送信成功または最終失敗後に削除
- 未送信の場合も最大24時間で削除
- Androidバックアップおよび端末移行バックアップの対象外
- 平文HTTP通信を禁止

ただし、端末やOSの挙動、ストレージ媒体の特性等により、物理的な完全消去を保証するものではありません。

## 5. Dify接続情報

Dify API Base および Dify App API Key は、Android Keystoreを利用して暗号化し端末内に保存します。

これらの値は本アプリの配布APK/AABには含まれません。利用者はアプリ内の接続設定から削除できます。

## 6. 広告について

本アプリは広告表示のため Google AdMob（Google Mobile Ads SDK）および Google User Messaging Platform (UMP) SDK を使用します。

GoogleのSDKは、広告配信、分析、不正防止等の目的で、IPアドレス、アプリとのインタラクション、診断情報、デバイス関連識別情報等を処理する場合があります。

本アプリでは Android Advertising ID (`AD_ID`) 権限をマニフェストから削除し、Advertising IDへのアクセスを無効化する構成としています。ただし、Google Mobile Ads SDKによるその他のデータ処理がすべて停止することを意味するものではありません。

必要な地域では UMP による同意確認を行い、Googleの要件上プライバシーオプションが必要な場合はアプリ内に設定入口を表示します。

Googleによるデータ処理についてはGoogleのプライバシーポリシーおよび広告関連ポリシーをご確認ください。

## 7. ログ・通知

本アプリは独自のアクセス解析SDKやクラッシュ解析SDKを組み込んでいません。

保存完了通知にはメモ本文、URL、ファイル名、Difyレスポンス本文を表示しません。Dify APIのエラーレスポンス本文も通知やアプリ独自ログへ保存しない設計です。

## 8. スクリーンショット等

本アプリは共有内容やAPI設定がOSのタスクスナップショット等へ残るリスクを低減するため、Androidのセキュアウィンドウ設定を利用します。

## 9. データの削除

端末内のDify接続情報はアプリ内の「Dify接続設定」から削除できます。

アプリをアンインストールすると、通常は本アプリのアプリ専用領域に保存されたデータも削除されます。

Difyへすでに送信済みのデータは、本アプリのアンインストールでは削除されません。Dify側で削除してください。
