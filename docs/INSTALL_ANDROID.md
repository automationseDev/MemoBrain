# Android 導入手順

## GitHub Releasesからインストール

1. [GitHub Releases](https://github.com/automationseDev/MemoBrain/releases/latest)を開きます。
2. `MemoBrain-<version>-release.apk` をダウンロードします。
3. Androidの確認画面に従ってAPKをインストールします。
4. 必要な場合だけ、APKを開いたブラウザ等へ「この提供元からのアプリを許可」を一時的に設定します。
5. インストール後、不要であれば提供元の許可をオフへ戻します。

GitHub以外のアプリストアでは配布していません。APKと同じReleaseにある `SHA256SUMS.txt` でファイルを確認できます。

## 更新

v1.0.0と同じ正式署名APKであれば、アプリを削除せず上書き更新できます。アプリを削除すると端末内の設定と送信履歴も削除されます。

## 初回確認

1. Dify接続設定を保存
2. テキスト共有を保存
3. URL / YouTube URLを保存
4. 画像またはPDFを共有
5. バックグラウンド保存通知と送信履歴を確認
6. Dify Knowledgeに保存されたことを確認
7. 同じURLまたはファイルの重複防止を確認
