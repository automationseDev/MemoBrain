# Android 導入手順

## GitHub Releases 版

GitHub Releases から署名済み `MemoBrain-<version>.apk` を取得します。GitHub はアプリストアではないため、Android 側で APK を取得したアプリ（ブラウザ等）に「この提供元からのアプリを許可」が必要になる場合があります。

インストール後、MemoBrain を起動し「Dify接続設定（必須）」を設定してください。

## Galaxy Store 版

Galaxy Store に公開された版も、GitHub Release 版と同じ `applicationId` と同じ署名鍵で配布する方針です。

## 初回確認

1. Dify接続設定を保存
2. テキスト共有を保存
3. URL / YouTube URLを保存
4. 画像またはPDFを共有
5. 保存後すぐ別アプリへ切り替え、バックグラウンド保存通知を確認
6. Dify Knowledge に保存されたことを確認
